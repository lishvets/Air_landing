# Air — Strategic Agency Landing Page

[Visit the Website]((https://lishvets.github.io/Air_landing))| [View Figma Design](https://www.figma.com/design/7qwsWggv9BAxMi2VPhBuPr/Air--formerly-Dia--?node-id=0-1&p=f&t=RUdgk4D2MOVpkoXH-0)

A sleek, sophisticated, and fully responsive landing page for Air — a full-service creative agency. The project showcases the agency's strategic approach, core expertises, services, client testimonials, and an interactive contact form.

## Project Overview

- **Tech Stack:** HTML5, SCSS, JavaScript
- **Architecture:** BEM (Block Element Modifier) methodology for modular and scalable styles
- **Quality & Standards:**
  - Fully valid, semantic HTML5 structure
  - Optimized image assets and SVG graphics for sharp high-DPI performance
  - Fluid responsiveness across Desktop, Tablet, and Mobile devices
  - Clean CSS resets and smooth cross-browser compatibility

## Architectural Details

- **Mobile-First Approach:** Built from the ground up starting with mobile viewports and progressively enhancing for larger displays.
- **SCSS Structure:** Organized with modular block components, reusable mixins, and design tokens (variables) for scalable code management.
- **Modern Layout Grid:** Combines CSS Grid and Flexbox for stable alignment of complex agency cards, expertise grids, and footer structure.
- **Interactive Forms & Navigation:** Features functional scroll navigation, slide showcase UI, and styled contact forms with input reset handlers.

## Features
- **Hero Slider Section:** Interactive banner showcasing key concepts with custom slide navigation controls.
- **Expertise & Services Showcase:** Well-structured grid components displaying agency competencies with custom-designed "Learn More" interactive elements.
- **Testimonials Section:** Dedicated social proof area featuring client feedback, photography, and custom quotes.
- **Interactive Drawer Menu:** Responsive side-navigation menu optimized for touch devices and small viewports.
- **Contact & Location Details:** Integrated message form alongside formatted phone, address, and social media links.
- **Pixel-Perfect Execution:** Precision styling aligned strictly with modern design guidelines.
